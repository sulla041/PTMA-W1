\section{Introduction}
\label{sec:intro}

The advent of large language models (LLMs) is fundamentally transforming integrated circuit (IC) design, enabling automated and rapid generation of hardware description code from high-level functional specifications. However, realizing the promise of software-like agile hardware development—characterized by continuous, push-button design iterations—critically hinges on accelerating the physical evaluation loop, which currently represents the primary bottleneck. While generative models can produce register-transfer level (RTL) code almost instantaneously, evaluating circuit properties still requires prolonged turn-around times to run synthesis, placement, and timing analysis. To bridge this disparity, foundational circuit modeling paradigms that can accurately and efficiently capture post-implementation characteristics are essential. Integrated circuits are naturally formulated as graphs, where logic cells and interconnects constitute nodes and edges endowed with rich and heterogeneous attributes, ranging from cell driving strengths to multi-dimensional routing parasitics. Moreover, predicting circuit characteristics inherently demands capturing long-range, multi-hop propagation dynamics across deep topological and causal logic chains. Consequently, pioneering dedicated graph learning algorithms specifically engineered to handle complex node-edge representations while scaling effectively across deep multi-hop circuit paths is of paramount theoretical and practical importance.
